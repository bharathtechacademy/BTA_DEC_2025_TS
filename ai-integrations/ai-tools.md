## Conversational AI Tools

## RAG ( Retrieval Augmented Generation )

Whenever a user is going to ask the question, the RAG framework is going to help us to identify the relevant data only. It is going to share details to LLM about particular information, and LLM is going to generate the answer. 

## MCP (Model Context Protocol )
MCP can take the knowledge from AI models available in the background, and also it can take the instruction from the user. It can take the control of your computer and software to perform the actions as well.
